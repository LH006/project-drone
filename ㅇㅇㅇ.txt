사이트 10개
ArduPilot(아두파일럿)은 드론, 무인 항공기(UAV), 지상 로봇, 잠수함 등 다양한 무인 이동체를 자율 제어하기 위한 세계에서 가장 앞선 오픈 소스 오토파일럿 시스템입니다. 
🛠️ 주요 특징 및 구성
다양한 기체 지원: 멀티콥터(ArduCopter), 고정익 비항기(ArduPlane), 지상 로버(ArduRover), 잠수함(ArduSub) 및 안테나 트래커 등을 모두 제어할 수 있습니다.
하드웨어 호환성: 초기에는 아두이노(Arduino) 기반이었으나, 현재는 픽스호크(Pixhawk) 계열의 강력한 32비트 하드웨어 및 리눅스 기반 싱글 보드 컴퓨터(Raspberry Pi 등)에서도 작동합니다.
오픈 소스 라이선스: GPLv3 라이선스를 따르며, 누구나 코드를 수정하고 공유할 수 있는 강력한 생태계를 갖추고 있습니다.
강력한 시뮬레이션: 실제 비행 전 소프트웨어 상에서 테스트할 수 있는 SITL(Software In The Loop) 기능을 제공하여 개발 비용과 위험을 줄여줍니다.

void loop() {
  // 1. 센서 데이터 읽기 (자이로/가속도)
  read_gyro_data(); 
  
  // 2. 목표 각도와 현재 각도 차이 계산 (오차)
  error = target_angle - current_angle;
  
  // 3. PID 계산을 통해 보정값 산출
  pid_output = (Kp * error) + (Ki * error_sum) + (Kd * error_diff);
  
  // 4. 각 모터에 속도 명령 전달 (PWM 신호)
  motor1_speed = throttle + pid_output;
  motor2_speed = throttle - pid_output;
  // ... 나머지 모터 적용
  
  analogWrite(motor_pin, motor1_speed);
}

4. 주의사항 및 팁

YMFC-AL(Your Mother's Flight Controller - Auto Level)은 네덜란드의 유튜버 Joop Brokking이 개발한 프로젝트로, 아두이노 우노(Arduino Uno)를 활용해 드론의 두뇌(FC)를 직접 만드는 전 세계에서 가장 유명한 교육용 프로젝트입니다.
이 프로젝트는 라이브러리를 거의 쓰지 않고 Raw Code(생코드)로 구현되어 있어, 드론의 제어 원리를 배우기에 최적입니다.
1. 🛠️ 핵심 하드웨어 구성
YMFC-AL을 제작하기 위해 필요한 표준 부품들입니다.
MCU: Arduino Uno (ATmega328P)
IMU(센서): MPU-6050 (자이로 + 가속도계)
프레임: 450급(F450) 또는 소형 드론 프레임
모터/변속기: 1000KV 브러시리스 모터 + 20A~30A ESC
배터리: 3S LiPo (11.1V)
송수신기: 4채널 이상의 PWM 방식 수신기 (Flysky i6 등)
2. 📂 소스 코드 구성 및 단계
YMFC-AL은 한 번에 코드를 올리는 방식이 아니라, 단계별 검증 과정을 거칩니다.
Hardware Test: 수신기 신호와 센서 데이터가 아두이노에 잘 들어오는지 확인합니다.
Setup Program: 센서의 수평(Calibration)을 잡고, 수신기의 스틱 범위를 메모리(EEPROM)에 저장합니다.
Flight Controller (Main): 실제 비행을 제어하는 핵심 소스입니다. (초당 250번의 루프 계산)
3. 💡 소스 코드의 특징 (핵심 로직)
Joop Brokking의 코드는 성능을 극대화하기 위해 다음과 같은 기법을 씁니다.
Interrupt 기반 수신기 읽기: digitalRead 대신 인터럽트를 사용하여 조종기 신호를 매우 빠르고 정확하게 읽습니다.
직접 레지스터 제어: 표준 analogWrite 대신 타이머 레지스터를 직접 건드려 ESC에 250Hz의 빠른 신호를 보냅니다.
상보 필터(Complementary Filter): 가속도계와 자이로 데이터를 조합하여 드론의 현재 각도를 계산합니다.
4. ⚠️ 제작 시 필수 체크리스트
이 프로젝트를 성공시키기 위해 가장 중요한 3가지입니다.
진동 방지: MPU-6050 센서는 진동에 매우 취약합니다. 폼 테이프 등으로 기체와 격리시켜야 합니다.
루프 타임 유지: loop() 함수가 정확히 4ms(250Hz)마다 실행되도록 코드가 설계되어 있습니다. 이 타이밍이 깨지면 드론이 추락합니다.
안전: 조종기의 스로틀을 내리고 왼쪽 아래로 내리면 시동(Arming), 오른쪽 아래로 내리면 정지(Disarming)되는 안전 로직이 포함되어 있습니다.
YMFC-AL 소스 코드를 아두이노 IDE에 업로드하기 전, 공식 웹사이트에서 제공하는 회로도와 핀 연결 가이드를 먼저 확인하셨나요? 필요하시다면 핀 연결 요약을 정리해 드릴 수 있습니다.

YMFC-AL(Your Mother's Flight Controller - Auto Level)의 소스 코드는 개발자인 Joop Brokking의 공식 웹사이트에서 다운로드할 수 있습니다.
이 프로젝트는 단순히 코드 하나만 올리는 게 아니라, 세팅용 코드와 비행용 코드가 나뉘어 있으니 순서대로 받으셔야 합니다.
📥 공식 다운로드 경로
공식 웹사이트: www.brokking.net - YMFC-AL 페이지
페이지 중간의 "Downloads" 섹션에서 압축 파일(.zip) 형태로 제공됩니다.
📂 필수 다운로드 파일 구성
압축을 풀면 보통 다음 파일들이 들어있습니다. (버전에 따라 이름이 조금 다를 수 있음)
YMFC-AL_Setup.ino (설정용)
가장 먼저 실행해야 합니다.
조종기(수신기) 신호 범위와 센서(MPU-6050)의 보정값을 아두이노 EEPROM(내부 저장소)에 기록합니다.
YMFC-AL_Flight_Controller.ino (실제 비행용)
설정이 끝난 후 최종적으로 업로드하는 메인 코드입니다.
EEPROM에 저장된 데이터를 불러와서 실제 드론을 제어합니다.
YMFC-AL_ESC_Calibration.ino (변속기 교정용)
4개의 모터 속도를 동일하게 맞추기 위해 변속기(ESC)를 동기화할 때 사용합니다.
⚠️ 주의사항 (업로드 전 확인)
라이브러리 불필요: YMFC-AL은 외부 라이브러리를 거의 사용하지 않고 레지스터를 직접 제어합니다. 따라서 별도의 센서 라이브러리를 설치할 필요가 없습니다.
회로 연결 필수: 소스 코드를 컴파일하기 전에 MPU-6050 센서와 수신기가 아두이노에 지정된 핀에 정확히 연결되어 있어야 'Setup' 단계가 통과됩니다.
